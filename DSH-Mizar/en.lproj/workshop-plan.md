# Community Repair Workshop

A two-hour drop-in event for neighbors to learn simple repairs together. Each repair station has a volunteer guide and a shared tray of hand tools.

## Running order

- **10:00–10:15** · Welcome, sign-in and a short safety briefing.
- **10:15–11:30** · Repair sessions at the mending, tightening and troubleshooting stations.
- **11:30–11:50** · Share one fix from each station and record useful tips.
- **11:50–12:00** · Return tools, clear tables and close out.

## Room setup

Use three tables with clear labels and leave a wide aisle between them. For an outdoor event, assign a sheltered sign-in table and keep an indoor backup for rain.
